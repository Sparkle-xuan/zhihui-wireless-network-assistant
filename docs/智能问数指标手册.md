# 智能问数指标与工具手册

本手册描述智徽当前受控查询工具和口径。规则与 `core.py`、`smart_query.py`、`network_query.py` 及数据库快照的实现一起维护；新增问法需先确认数据来源和统计口径，不能以模型猜测的字段或数字替代。

## 问数链路

1. 从当前问题及紧邻的相关用户问题提取日期、范围、指标和操作；对不明确的条件进行澄清。
2. 已实现的排名比较、挂起原因等场景由 `query_router.py` 构建受限查询计划，其余查询由既有日报、黑点或规划器处理。尚未实现的场景须明确提示。
3. 程序选择已保存快照并执行固定查询与计算；模型不执行任意 SQL。缺失、冲突和无分母不能当作 0。
4. 返回必要的数据日期、版本、口径与表格；关键词初筛必须标明可重叠且不代表已确认原因。
5. 用户连续追问时只沿用紧邻的相关问题；需要排名或对比时重新计算，不把模型先前回答作为数据来源。

## 指标目录

| 领域和指标 | 常见说法 | 数据来源与口径 | 支持范围 |
| --- | --- | --- | --- |
| 黑点解决率 | 合格率、解决情况 | 当期快照中质检合格数 ÷ 确认纳入数；全省使用总分子和总分母 | 按月、全省/单地市/各地市；地市排名和部分两月比较 |
| 黑点确认纳入数 | 已纳入、入库数 | 当期快照的确认纳入数 | 按月、全省/地市 |
| 黑点质检合格数 | 质检合格多少 | 当期快照的质检合格数 | 按月、全省/地市 |
| 平台汇聚黑点量 | 汇聚黑点量 | 汇聚表中全部记录，非仅确认纳入记录 | 按月、全省/地市，需快照保存该字段 |
| 关联投诉量 | 汇聚关联投诉、已纳入关联投诉 | 汇聚范围和已纳入范围分别统计；未指明时同时展示两个口径 | 按月、全省/地市，需快照保存对应字段 |
| 黑点项目进展 | 建设进展、各整治阶段 | 已确认纳入且当前为地市处理节点，按七个项目阶段统计 | 按月、全省/地市，需快照保存阶段汇总 |
| 挂起库数量 | 申请挂起、挂起多少 | 使用当前选定的挂起库版本；挂起表与汇聚表统计不一致时提示核对 | 按月、全省/地市；支持地市排名、与另一月对比及连续范围追问；人工汇总可能只有部分地市 |
| 挂起原因关键词 | 不纳入原因、为什么挂起 | 来源于当前选定版本已保存的“不纳入原因”关键词汇总 | 单月、全省或单个地市；允许多关键词命中，非已确认原因 |
| 问题形成原因关键词 | 挂起问题形成原因 | 来自“问题形成原因”字段的独立关键词汇总 | 单月、全省或单个地市；不能与不纳入原因混为同一口径 |
| 网络运行日报 | 5G流量、用户数、接通率等 | 已保存的日报和 CSV 汇总，指标和单位以 `network_query.METRICS` 为准 | 按日、全省/地市；支持日报概览、两日指定指标对比及部分范围追问 |

## 日期与版本

- 普通黑点月度快照采用当月最后一个周五；同日周报和月报存在时按现有查询规则选取，并展示来源。
- 挂起库允许指定历史工单表或人工汇总作为当月版本；人工通报未提供统计日期时不能推断具体日期。缺失的地市不补零。
- 地市解决率排名排除确认纳入数为零的地市，末位并列一并展示；比较按未四舍五入的数值计算，变化单位为百分点。
- 例如“2026年10月各地市黑点解决率”→“倒数前三”→“和9月比”，第三次请求会重新读取 10 月排名及 9 月快照，不使用上次回答文字中的数字。
- 未明确年份的月份按现有本机当前年份或相邻问题中的明确年份处理；涉及不同年份或不明确时应明确写出年份。

## 连续追问示例

- “2026年10月合肥挂起多少” → “宣城呢” → “和9月比呢”：沿用月份和指标，只比较两个版本均有的地市值。
- “2026年10月各地市挂起数量最多的前两名”：按已保存的完整地市分布排名，末位并列一并显示；数据不全不排名。
- “2026年10月21日全省5G流量与10月20日相比”：比较同一指标和范围的两个具体日期；缺一天则提示不可比较。
- 上述追问仅沿用紧邻的相关问题；涉及其他话题、多个地市、多个指标或不明确的日期时，应分开提问。

## 页面导航与操作边界

- 助手可识别“打开10月挂起库”“打开2026年11月2日网络日报”“打开话术模拟”等明确请求，在回答中提供页面入口。支持识别部分地市范围的连续追问，遇到话题切换会清除旧的查询条件。
- 页面入口由前端固定白名单生成，点击后在新标签页打开。指定月份或日期不可用时，目标页面显示缺失提示，不自动替换为其他日期。
- “生成月报”等请求只引导到报告工作台；上传、生成、覆盖和发邮件仍需用户在相应页面核对后操作。普通查询和报告内容不会因为提供入口而被修改。

## 数据保护与扩展

- 黑点原因问数只返回已经保存的聚合关键词，不上传或展示原始 Excel、工单明细或原始原因文本。
- DeepSeek 在现有意图规划与总结流程中接收的问题或汇总应符合页面说明；不得为此扩大发送原始工单、报告或凭据。
- 新增查询前先记录指标定义、粒度、数据日期、可用字段和缺失行为，再补充包含正常、缺失、并列和上下文干扰的测试；不要仅通过扩大关键词来假设功能已经支持。
