# 智徽无线网络感知分析助手

## 本机启动

需要 Python 3.10 或以上及 requirements.txt 中的依赖。首次运行 `python -m pip install --target .deps -r requirements.txt`，再双击 `start.bat`。首次按提示输入本机 PostgreSQL 用户名、项目数据库名和密码后，成功连接时自动保存到当前 Windows 账户的凭据管理器；之后双击即可自动连接。打开 http://127.0.0.1:5088 使用。服务仅监听本机，关闭启动窗口会停止服务。

上传 2026 年工单表时，页面会尝试从文件名中的完整日期自动填写统计日期，无法唯一识别时请手动选择；统计日期始终可以修改。点击“生成周报”只需该表；点击“生成月报”还需上传包含「遗留94处」的历史工单表。周报首次使用请提供上一周黑点入库数及质检合格数；以后仅在恰有七天前的快照时自动使用，否则提示补录。月报建议选当月最后一个周五的数据。

使用 `start.bat` 时，报告和统计快照保存至本机 PostgreSQL，默认数据库名为 `zhihui`，不存在时将尝试创建。密码保存在当前 Windows 账户的凭据管理器，并在运行时传给服务进程，不写入代码或项目配置文件。页面的“数据库设置”可以验证并更新保存的连接信息，密码留空时仅为同一用户名保留已有密码；设置在下次启动生效，不会更改 PostgreSQL 用户自身的密码。原有 `instance/zhihui.sqlite3` 会只读复制到 PostgreSQL，原文件保留；若同一日期已有不同内容，迁移停止而不覆盖任何数据。同内容不重复导入。请定期备份 PostgreSQL 数据库。

上传原文件不保存。修改报告文字后点击“保存修改”，下次打开历史报告即可看到保存结果。请勿将业务原始文件、快照或密码提交 GitHub。新生成的周报和月报分别保存统计汇总，包含全省及地市统计、整治阶段、全球通、归档、挂起库地市及类别汇总；月报还包括历史遗留汇总。系统不保存原始工单明细。旧周报缺失细分数据时，可选生成该报告的当期原表和日期，点击“补充周报统计”。系统会先核对历史保存的全省、各地市和挂起库已有统计，校验不一致则停止；校验一致只补缺失汇总，不修改报告文字。已有汇总一致不能完全证明明细相同，仍需选择生成报告的原始版本。月报快照不由此功能修改。直接运行 `python app.py` 仍使用独立的 SQLite，只用于本地开发或故障排查，不应与 PostgreSQL 并行使用。

## QQ 邮箱发送

生成或打开报告后，在下方灰色“邮箱设置”中填写 QQ 发件邮箱、一个收件邮箱和 QQ 邮箱 SMTP 授权码，确认主题与报告文字后，点击报告旁的“发送邮件”。月报可以选择附带 Excel。首次使用需要在 QQ 邮箱中开启 SMTP 服务并生成授权码；授权码不是 QQ 登录密码。点击“保存授权码”可将其保存在当前 Windows 账户的凭据管理器中，下次自动填入发件邮箱、对相同发件邮箱发送时授权码可留空；发件邮箱也可修改。不点击保存则授权码只在当次发送使用。可使用“删除已保存授权码”清除保存项。授权码不会写入数据库或项目文件。SMTP 采用 QQ 邮箱 `smtp.qq.com:465` 和 SSL。发送结果显示服务器是否接受；如发送状态不确定，请先检查发件箱，避免重复发送。

报告文字中的挂起原因和工程推进说明必须人工填写审核。投资与成本统计针对全部纳入项目，不等同于未解决项目分类，月报中不自动断言这一数字。同一天的周报和月报分别保存；重新生成同一天的同类报告会替换该报告。历史表日期不从文件名推定，须自行核对。

## 智徽问答助手

鼠标悬停在页面悬浮机器人上，选择文字或语音按钮打开问答窗口；触屏可先点击机器人显示按钮。拖动机器人可调整位置；键盘聚焦机器人后也可用方向键移动。首次在“DeepSeek 设置”中保存 API 密钥，密钥保存于当前 Windows 账户的凭据管理器，可在同处更换或删除，不写入项目文件或数据库。提问和当前会话内容会发送至 DeepSeek，调用可能产生账户费用；聊天记录仅保留在当前页面内，刷新后清空。聊天不会自动引用报告文字。

聊天窗口右上角的设置中可选择 DeepSeek Flash 或 DeepSeek V4 Pro，选择自动保存到当前浏览器。普通聊天、问数意图识别及查询结果总结使用同一个所选模型；默认 Flash。Pro 费用较高，模型价格和可用性以 DeepSeek 官方为准。

语音输入依赖浏览器支持。语音识别可能由浏览器供应商的在线服务处理；识别结果可在发送前修改。无法使用语音时仍可使用文字聊天。

智能问数支持按月查询全省或地市确认纳入数、质检合格数、解决率、挂起库数量、汇聚黑点量、关联投诉量和项目进展。关联投诉量口径不明确时同时显示平台汇聚和已确认纳入的两个数；项目进展只统计已纳入且处于地市处理节点的七个阶段。问题发送给 DeepSeek 识别查询意图；统计查询在本机执行，成功查询后将本次问题和查询所需汇总结果发送给 DeepSeek 生成总结，不自动发送原始 Excel 和工单明细。回答可展开查看本地统计依据，AI 可能理解有误，请核对依据；AI 总结不可用时显示本地统计结果。汇总结果不随后续对话历史再次发送。模型只能选择受控工具，不执行模型生成的 SQL。查询月份默认使用当月最后一个周五的统计，同日有月报快照时优先使用月报；没有当天报告会提示补录，不用其他日期替代。未注明年份时默认本机当前年份，并在结果中显示。旧快照可能缺少这些细分统计，此时提示重新导入该期文件，不当作零。“申请挂起”与“挂起库数量”统一作为同一业务指标查询；已保存的挂起表与汇聚表数量不一致时提示核对。

### 网络运行历史数据入库（准备阶段）

- 本机接口可将用户提供的历史日报正文与指标 CSV 分别存入数据库；重复导入相同文件不会新增副本。
- 日报仅保留原文，标记为待核对，尚未提取成可查询的指标；CSV 保留原始数值和空值，不将缺失视为零。
- 同一 CSV 内日期、地市相同且数值有差异的记录均标记为冲突；完全相同的重复行只保留一份。不同来源之间的差异仍需单独核对，不能直接用于自动生成日报。
- 历史数据入库阶段只负责数据保存；后续网络日报功能见下文。用户提供的数据和本地数据库不应提交到 Git。

### 网络运行情况模块（第一版）

- 支持按日期查看历史日报、全省关键指标和地市 CSV 指标；历史日报正文可编辑并另存为草稿，原文保留。
- 使用已入库的全省指标生成包含缺项提示的初步草稿；网络质量、专题及投诉等未接入的数据需要人工补充，不能将其当作完整日报。
- 5G、4G 流量和 5G 分流比可从历史原文中提取；如与 CSV 对应值不一致，页面隐藏该指标并提示核对。CSV 中存在冲突的指标不显示数值，缺失不视为零。
- 数据导入目前支持历史日报 TXT 和现有指标 CSV。其他数据库、接口及定时获取尚未接入；发送邮件需人工核对并点击发送。

### 网络运行日报网页表格

- 日报预览按所选日期呈现全省用户与业务量、地市用户、地市业务量及感知速率、地市网络质量四张表；宽表可横向滚动。
- 表格取自对应日期已入库的指标及可核对的日报正文，缺失或冲突项显示“—”；CSV 的较上月对比口径尚待核实，不展示数值；历史日报表格保留原文中的对比值。
- 页面从历史日报原文恢复文字及表格并按原顺序交错展示；文字和表格可分别编辑，保存为独立草稿。复制含文字与表格，邮件使用 HTML 正文及纯文字备用版本发送当前文字和表格。

正文按连续区域合并编辑入口，编辑模式提供字体、字号、颜色、加粗、斜体和下划线。选中文字后设置样式；保存草稿及邮件 HTML 保留样式，纯文字邮件备用内容不保留样式。旧草稿无需迁移。

### 无线网络运行日报问数

- 机器人可按单日查询全省、单个地市或全部地市的指定指标，包括 4G/5G 流量、分流比、用户、感知速率、网络质量，以及历史日报中部分 5G-A、通感和 RedCap 汇总。
- 说明日期（如“2026年10月21日”）和范围，或明确指定“最新”；最新指已有日报或 CSV 的最新日期，缺少所问指标时不改用其他日期。支持全省或单个地市按“昨天比前天”比较同一指标；其他跨日期对比、趋势及排名暂不支持。百分比指标按百分点比较，缺失、冲突或分母为零会提示。
- 只读取保存的历史日报原文和指标 CSV；编辑草稿不会自动改写历史统计。缺失与来源差异会明确提示，不补零。地域汇总可发送给 DeepSeek 总结，小区、站点及用户明细、原始报表不会发送。

网络日报指标、日报概览及黑点月度问数在 PostgreSQL 模式下使用 E 盘 Wren 模型读取已保存的数据；日报指标仍与本机历史日报进行原有一致性核对。Wren 不可用时提示失败，不静默换用其他数据。问题识别仍由现有规则和 DeepSeek 工具规划处理。Wren 工作进程不接收模型生成的 SQL，数据库连接使用启动时的本机凭据；不发送原始日报或指标 JSON 到 DeepSeek。

挂起库推进页面按月份展示每月最后一个周五的黑点周报快照；同日无周报但有月报时使用同日月报，并标明来源。展示全省挂起数量、16 地市固定顺序柱状图、分类环形图及挂起数量最多地市预警榜（第三名并列一并展示），与上一自然月的月末报告比较总量和各地市数量；缺少对应日期或地市数据时明确提示，不以其他日期替代。

挂起库支持补录历史月份的汇总数据，单独保存在本机数据库，不覆盖周报；只录入已知地市并保留未知值。同月存在月末周报时优先使用周报。补录汇总的具体统计日期未提供时不推断日期，月度对比仅计算数据已知的地市。
