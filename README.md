# 智徽无线网络感知分析助手

## 本机启动

需要 Python 3.10 或以上及 requirements.txt 中的依赖。首次运行 `python -m pip install --target .deps -r requirements.txt`，再双击 `start.bat`。首次按提示输入本机 PostgreSQL 用户名、项目数据库名和密码后，成功连接时自动保存到当前 Windows 账户的凭据管理器；之后双击即可自动连接。打开 http://127.0.0.1:5088 使用。服务仅监听本机，关闭启动窗口会停止服务。

上传 2026 年工单表时，页面会尝试从文件名中的完整日期自动填写统计日期，无法唯一识别时请手动选择；统计日期始终可以修改。点击“生成周报”只需该表；点击“生成月报”还需上传包含「遗留94处」的历史工单表。周报首次使用请提供上一周黑点入库数及质检合格数；以后仅在恰有七天前的快照时自动使用，否则提示补录。月报建议选当月最后一个周五的数据。

使用 `start.bat` 时，报告和统计快照保存至本机 PostgreSQL，默认数据库名为 `zhihui`，不存在时将尝试创建。密码保存在当前 Windows 账户的凭据管理器，并在运行时传给服务进程，不写入代码或项目配置文件。页面的“数据库设置”可以验证并更新保存的连接信息，密码留空时仅为同一用户名保留已有密码；设置在下次启动生效，不会更改 PostgreSQL 用户自身的密码。原有 `instance/zhihui.sqlite3` 会只读复制到 PostgreSQL，原文件保留；若同一日期已有不同内容，迁移停止而不覆盖任何数据。同内容不重复导入。请定期备份 PostgreSQL 数据库。

上传原文件不保存。修改报告文字后点击“保存修改”，下次打开历史报告即可看到保存结果。请勿将业务原始文件、快照或密码提交 GitHub。新生成的周报和月报分别保存统计汇总，包含全省及地市统计、整治阶段、全球通、归档、挂起库地市及类别汇总；月报还包括历史遗留汇总。系统不保存原始工单明细。旧周报缺失细分数据时，可选生成该报告的当期原表和日期，点击“补充周报统计”。系统会先核对历史保存的全省、各地市和挂起库已有统计，校验不一致则停止；校验一致只补缺失汇总，不修改报告文字。已有汇总一致不能完全证明明细相同，仍需选择生成报告的原始版本。月报快照不由此功能修改。直接运行 `python app.py` 仍使用独立的 SQLite，只用于本地开发或故障排查，不应与 PostgreSQL 并行使用。

## QQ 邮箱发送

生成或打开报告后，在下方灰色“邮箱设置”中填写 QQ 发件邮箱、一个收件邮箱和 QQ 邮箱 SMTP 授权码，确认主题与报告文字后，点击报告旁的“发送邮件”。月报可以选择附带 Excel。首次使用需要在 QQ 邮箱中开启 SMTP 服务并生成授权码；授权码不是 QQ 登录密码。点击“保存授权码”可将其保存在当前 Windows 账户的凭据管理器中，下次自动填入发件邮箱、对相同发件邮箱发送时授权码可留空；发件邮箱也可修改。不点击保存则授权码只在当次发送使用。可使用“删除已保存授权码”清除保存项。授权码不会写入数据库或项目文件。SMTP 采用 QQ 邮箱 `smtp.qq.com:465` 和 SSL。发送结果显示服务器是否接受；如发送状态不确定，请先检查发件箱，避免重复发送。

报告文字中的挂起原因和工程推进说明必须人工填写审核。投资与成本统计针对全部纳入项目，不等同于未解决项目分类，月报中不自动断言这一数字。同一天的周报和月报分别保存；重新生成同一天的同类报告会替换该报告。历史表日期不从文件名推定，须自行核对。

## 智徽问答助手

鼠标悬停在页面悬浮机器人上，选择文字或语音按钮打开问答窗口；触屏可先点击机器人显示按钮。拖动机器人可调整位置；键盘聚焦机器人后也可用方向键移动。首次在“DeepSeek 设置”中保存 API 密钥，密钥保存于当前 Windows 账户的凭据管理器，可在同处更换或删除，不写入项目文件或数据库。提问和当前会话内容会发送至 DeepSeek，调用可能产生账户费用；聊天记录仅保留在当前页面内，刷新后清空。聊天不会自动引用报告文字。

聊天窗口右上角的设置中可选择 DeepSeek Flash 或 DeepSeek V4 Pro，选择自动保存到当前浏览器。普通聊天、问数意图识别及查询结果总结使用同一个所选模型；默认 Flash。Pro 费用较高，模型价格和可用性以 DeepSeek 官方为准。

语音输入依赖浏览器支持。语音识别可能由浏览器供应商的在线服务处理；识别结果可在发送前修改。无法使用语音时仍可使用文字聊天。

智能问数支持按月查询全省或地市确认纳入数、质检合格数、解决率、挂起库数量、汇聚黑点量、关联投诉量和项目进展。关联投诉量口径不明确时同时显示平台汇聚和已确认纳入的两个数；项目进展只统计已纳入且处于地市处理节点的七个阶段。问题发送给 DeepSeek 识别查询意图；统计查询在本机执行，成功查询后将本次问题和查询所需汇总结果发送给 DeepSeek 生成总结，不自动发送原始 Excel 和工单明细。回答可展开查看本地统计依据，AI 可能理解有误，请核对依据；AI 总结不可用时显示本地统计结果。汇总结果不随后续对话历史再次发送。模型只能选择受控工具，不执行模型生成的 SQL。查询月份默认使用当月最后一个周五的统计，同日有月报快照时优先使用月报；没有当天报告会提示补录，不用其他日期替代。未注明年份时默认本机当前年份，并在结果中显示。旧快照可能缺少这些细分统计，此时提示重新导入该期文件，不当作零。涉及“申请挂起”的问题与挂起库口径不同，当前不支持按申请挂起工具查询。
