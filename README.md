# 智徽无线网络感知分析助手

## 本机启动

需要 Python 3.10 或以上及 Flask、openpyxl。首次运行 `python -m pip install -r requirements.txt`，再双击 `start.bat`，打开 http://127.0.0.1:5088 。服务仅监听本机。

在页面选定数据日期，上传 2026 年工单表和包含「遗留94处」的历史工单表，生成并核对报告。首次使用请提供上一周黑点入库数及质检合格数；以后仅在恰有七天前的快照时自动使用，否则提示补录。月报建议选当月最后一个周五的数据。

生成的统计快照保存在 `instance/zhihui.sqlite3`，不保存上传原文件。该目录已被 Git 忽略。请定期备份数据库文件。为便于本机先试运行，本版采用 SQLite；PostgreSQL 尚未连接，迁移时需另行配置。请勿将业务原始文件、快照或密码提交 GitHub。

报告文字中的挂起原因和工程推进说明必须人工填写审核。投资与成本统计针对全部纳入项目，不等同于未解决项目分类，月报中不自动断言这一数字。每次重新生成同一日期会替换原有快照。历史表日期不从文件名推定，须自行核对。
