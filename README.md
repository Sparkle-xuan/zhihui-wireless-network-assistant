# 智徽 · 无线网络感知分析助手

面向无线网络运维与投诉处理的本地 Web 工作台。智徽将重点投诉区域统计、挂起库推进、网络运行日报和投诉话术整理在一起，帮助使用者从已有数据中生成报告、查看趋势并辅助沟通。

> 当前为 Windows 本机试运行版本，服务默认只监听本机。生成内容和 AI 建议均需结合实际情况人工核对。

## 功能概览

| 模块 | 当前能力 |
| --- | --- |
| 数据总览 | 首页展示安徽 16 地市地图，可切换网络日报、黑点解决率和挂起数量，按指标选择对应日期或月份；缺失及来源冲突的数据不按零展示。 |
| 黑点周报与月报 | 导入工单 Excel，统计全省及地市重点投诉区域数据，生成并编辑报告；月报支持导出 Excel。 |
| 挂起库推进 | 查看月度挂起数量、地市分布、分类构成、重点地市和环比变化；基于已保存的汇总生成诊断建议。 |
| 网络运行情况 | 查看历史日报及指标，编辑图文和表格，生成日报草稿、导出 Word，并在核对后发送邮件。 |
| 投诉分析 | 按服务场景查询规范话术；在话术模拟中扮演用户，与模拟客服进行多轮对话。 |
| 智能助手 | 在各页面通过悬浮机器人进行文字问答、语音转文字和已接入指标的智能问数。 |
| 本期值得关注 | 在工作台按所选月份展示本地汇总计算的地市排名、连续下降、挂起变化和到期事项；网络流量对比仅在两日数据可用时显示。 |
| 问数测试台 | 本机运行固定和人工确认的意图测试，使用模拟数据检查计算及缺数提示；不调用外部模型。 |
| 月度智能分析报告 | 基于已保存的月度统计，经 LangGraph 流程生成地市解决率图文分析，可预览、下载 HTML 并核对邮件草稿后手动发送。 |
| 地市提醒与定时检查 | 默认按解决率倒数生成草稿；可配置解决率、未完成数量、连续下降及挂起增长规则。定时检查仅生成待核对草稿，用户逐封确认发送。 |
| 地市推进跟踪 | 记录关注事项、处理措施、状态及下次跟进时间；保留推进历史，并在数据可用时比较下月解决率。 |

侧边栏或页面顶部的“快速前往”可搜索并打开本地功能页面；不在输入框中时，也可按 `Ctrl + K`（macOS 为 `Command + K`）打开。周月报或话术存在未保存内容时，使用该入口离开会先提示。

### 黑点报告与挂起库

- 周报使用当年工单进展表；月报还需历史工单表。系统会尝试从文件名识别统计日期，也支持手动修改。
- 周报的本周新增和本周解决需要上一周基准；没有恰好七天前的统计快照时，可按提示补录。
- 月度统计通常采用当月最后一个周五的周报快照。挂起库也可导入指定历史工单表，或补录人工汇总；不同版本会标明来源。
- 旧表缺少归属类别时，可选择对原因关键词进行初筛；初筛可能重叠或无法分类，结果需人工核实。
- 挂起诊断根据可用的数量、类别、原因关键词汇总和月度变化生成建议。诊断结果保存在本机数据库，数据变化后可重新生成。
- 在挂起库选择月份和地市，可查看挂起障碍、问题形成原因及同一记录的跨字段关键词汇总和本地参考建议。关键词可能重复命中，不代表已经确认的原因。
- 可按原因字段和现有关键词标签维护本地推进建议；命中时在地市分析中展示，建议不会自动发送给模型或地市。
- 黑点报告页可对照两个已保存的周报或月报版本，查看文字、全省汇总和地市纳入数及解决率；差值按右侧减左侧计算，缺失值显示为“—”。
- 在月度分析报告页可检查本月与上月数据的实际来源日期；缺少上月时报告仍可生成，但不会编造环比。
- 地市提醒页面可将告警带入推进台账，也可手工新建。结果变化仅表示两个统计期解决率的变化，不证明由某项措施导致。
- 推进台账可筛选状态和已到期事项，按记录展示前一期、本期及后两期的解决率和挂起数量；缺数不补零。

### 网络运行日报

- 首页“智能观察”展示本地计算的重点地市和两期变化。网络指标对比前一自然日，黑点指标对比上一个自然月；缺数或网络来源不一致时不计算变化。可在首页设置 5G 流量关注阈值，设置保存在当前浏览器。
- 点击地图或重点地市可查看该市概况、带入助手提问、生成单地市 HTML 报告或打开地市提醒。提醒和邮件需要人工核对、确认发送。
- 首页本地摘要由已保存的统计汇总计算；点击“生成 AI 解读”时，仅将本次统计汇总发送至 DeepSeek。密钥未配置或服务不可用时仍可查看本地摘要。
- 首页默认以最近已保存日报的 5G 数据流量展示地市地图；可选择日报日期或切换月度指标。地图底图使用阿里云 DataV.GeoAtlas 安徽地市行政边界数据，已保存在本地，展示时不需要将业务数据发送到地图服务。
- 当 16 市和全省 5G 流量均有数据时，首页会核对地市合计与全省总量；差异超过 0.10 TB 时暂停地市数值和排名，提示核对来源与口径，保留全省原始汇总。
- 支持导入历史日报文本和指标 CSV，按日期查看全省指标、地市数据及历史内容。
- 日报支持文字与表格交错展示、编辑、保存草稿、复制、导出 Word 和邮件发送。
- 可选择两个已保存日期并排查看日报文字、表格与指标；日报的“调整顺序”支持拖动或上移／下移文字和表格块，“并排预览”可检查当前内容并调整宽度，排序需保存草稿后生效。
- 首页地图及挂起库图表支持悬停、键盘聚焦或触屏查看数值和统计日期；操作通知保留页面原有提示，邮件发送状态以服务返回的实际信息为准。
- 根据已入库指标生成的是**初步草稿**：缺失、冲突或尚未接入的内容需要人工补充和核对。
- 外部数据库、接口的自动采集尚待数据来源确定后接入；邮件需人工核对后点击发送。

### 智能问数与语音

- 已接入部分黑点月度指标、挂起数量及无线网络运行日报指标，并支持部分比较与排名场景。查询能力以页面返回的实际范围为准；缺失或冲突的数据不会自动当作零。
- DeepSeek 用于部分意图规划、对话和汇总解释；统计计算和数据读取由本机程序及受控工具执行。请结合展示的统计依据核对结果。
- 首次使用时，在悬浮助手的设置中保存 DeepSeek API 密钥；可选择当前支持的模型。模型服务可能产生费用。
- 可请求助手提供挂起库、网络日报、话术模拟和报告工作台的页面入口；用户点击后打开，生成报告及发送邮件仍需在页面确认操作。
- 支持查询人工维护的地市推进台账。对错误回答的反馈可填写人工核对后的期望结果；这些记录不会自动改变查询规则。项目中的离线验收题使用模拟数据，不调用模型。
- 对“某月哪些地市黑点解决情况需要关注”，可继续询问“第一个地市主要卡在哪个环节”，再打开推进表单；排名并列、会话过期或数据变化时要求重新确认。排名凭证仅用于本机查询上下文校验，不自动提交或发送。
- 语音输入依赖浏览器的语音识别能力和麦克风权限。识别文字可编辑后发送；音频可能由浏览器供应商的语音服务处理。

## 技术栈

- **后端：** Python、Flask
- **前端：** HTML、CSS、JavaScript
- **本地存储：** PostgreSQL；开发或故障排查可使用独立的 SQLite
- **数据与文档：** openpyxl、python-docx
- **模型与查询：** DeepSeek API；部分 PostgreSQL 问数使用本机 Wren 读取已保存数据

## 快速开始

### 运行环境

- Windows 及 Python 3.10 或更高版本
- 本机 PostgreSQL 服务（默认 `127.0.0.1:5432`）
- 可使用 JavaScript 的现代浏览器

按需准备 DeepSeek API 密钥和 QQ 邮箱 SMTP 授权码。Wren 是部分 PostgreSQL 智能问数的额外依赖，不包含在本仓库中。

### 安装与启动

在 PowerShell 中进入项目目录并安装依赖：

```powershell
cd D:\zhihui-wireless-network-assistant
python -m pip install --target .deps -r requirements.txt
```

双击项目目录下的 `start.bat`，或在 PowerShell 中运行：

```powershell
.\start.bat
```

首次启动时按提示输入 PostgreSQL 用户名、数据库名称和密码。默认数据库名为 `zhihui`；不存在时程序会尝试创建，需要相应权限。连接成功后，凭据可保存在当前 Windows 账户的凭据管理器中，后续可在页面的“数据库设置”里修改。

启动后访问 **http://127.0.0.1:5088/**。关闭启动窗口会停止服务。

直接运行 `python app.py` 使用独立的 SQLite 数据库，适合本地开发或排查；它与 `start.bat` 使用的 PostgreSQL 数据相互独立，不应混用。

### 可选配置

**DeepSeek API 密钥。** 仓库不提供或保存个人密钥，请在运行后的网页中自行配置：

1. 打开智徽页面，点击或悬停页面上的机器人，在快捷菜单中选择“文字聊天”。
2. 点击聊天窗口右上角的设置图标，展开“DeepSeek 设置”。
3. 在“DeepSeek API 密钥”输入框中填写自己的密钥，点击“保存密钥”。可在同一设置中更换或删除密钥，并选择模型。

密钥保存在当前 Windows 账户的凭据管理器中，供本机运行时读取，不需要写入 README、代码或项目配置文件，也不要提交到 GitHub。配置后可用于智能助手、话术模拟等需要 DeepSeek 的功能；没有配置时仍可使用不依赖模型的本地功能。

**邮件发送。** 在报告页面的邮箱设置中填写 QQ 发件邮箱、收件邮箱和 SMTP 授权码，核对内容后手动发送。授权码可保存在当前 Windows 账户的凭据管理器；月报可选择附带 Excel。SMTP 服务是否接受邮件不等于收件方已收到，状态不确定时请先检查发件箱。

**本机 Wren。** PostgreSQL 模式下，部分日报及黑点问数使用本机 Wren 工作进程。默认 Python 环境路径为 `E:\zhihui-wren\venv\Scripts\python.exe`，也可通过 `ZHIHUI_WREN_PYTHON` 指定；本仓库不包含该环境。Wren 不可用时，相关查询会提示检查配置。程序使用受控查询，不直接执行模型生成的任意 SQL。

## 数据与隐私

- 黑点工单 Excel 用于本地统计；报告文字和必要统计汇总保存在本机数据库。首页重点投诉区域明细可额外保存已确认纳入区域的地市、区域名称、黑点类型、入库时间和当前节点，不保存原表、联系人或工单编号；仅展示与所选月度快照日期和纳入数量核对一致的版本。近 30 天按该快照日期和入库时间筛选。
- 网络运行模块可保存用户导入的历史日报原文、指标及编辑草稿。请按实际业务要求管理和备份数据库。
- 智能问数、挂起诊断和话术模拟可能将问题或相关汇总发送至 DeepSeek；页面会提示发送范围。话术模拟请先脱敏，勿输入姓名、电话或详细地址。
- 数据库密码、DeepSeek 密钥和 QQ 邮箱授权码不应写入代码或提交仓库；项目使用 Windows 凭据管理器保存相关凭据。
- `.gitignore` 排除了业务表格、本地数据库、环境变量文件和生成报告。提交前仍应检查暂存内容，避免上传业务数据或敏感信息。

## 项目结构

```text
├── app.py                    # Flask 路由及应用入口
├── core.py                   # 黑点报告统计与导出
├── suspension.py             # 挂起库汇总与分析
├── suspension_reasons.py     # 挂起原因关键词汇总
├── complaint_routes.py       # 投诉话术接口
├── network_daily.py          # 网络运行日报与指标
├── smart_query.py            # 受控问数工具
├── intent_router.py          # 已支持问数场景的识别优先级
├── assistant_service.py      # 模型调用与结果处理
├── templates/                # 页面模板
├── static/                   # 页面样式、脚本和素材
├── tests/                    # 自动化测试
├── 需求说明.md               # 业务范围及统计口径
├── requirements.txt          # Python 依赖
└── start.bat                 # Windows 本机启动入口
```

## 测试

安装依赖后，可以按模块运行测试，例如：

```powershell
python -m unittest discover -s tests -p 'test_complaint*.py'
python -m unittest discover -s tests -p 'test_suspension*.py'
python -m unittest discover -s tests -p 'test_smart_query.py'
```

部分前端测试使用 Node.js，可按需运行，例如 `node tests/assistant-utils.test.js`。自动化测试不能替代对真实业务数据、浏览器语音能力和邮件送达情况的人工核对。

## 当前边界

- 本项目目前主要面向本机试运行；多用户权限、云端部署和移动端应用仍需进一步设计。
- 日报自动采集与更多数据源接口尚未接入；复杂问数仅覆盖已实现并经校验的场景。
- AI 生成的报告、话术和诊断建议应由使用者核实，不应将未确认的原因、方案或解决时间作为事实对外承诺。

更多业务规则请参阅 [需求说明](需求说明.md)，智能问数的指标口径和工具范围参阅 [智能问数指标手册](docs/智能问数指标手册.md)。
